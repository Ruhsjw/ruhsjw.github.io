# Jie Wu — Robotics Portfolio

Bilingual personal portfolio covering robotics, whole-body control, perception, and full-stack robot systems.

## Website

GitHub Pages destination: https://ruhsjw.github.io/

Publish the `main` branch from `/ (root)` in **Settings → Pages**. The site is static HTML, CSS, and JavaScript; no build step is required. `.nojekyll` preserves the files as provided.

## Editing

- `index.html`: page sections, publication citation, and navigation.
- `data.js` and `enrich.js`: bilingual projects, experience, and media captions.
- `app.js`: language switching, filters, showcase cards, and media previews.
- `style.css`: responsive layout.
- `media/`: project images and video thumbnails.

Video demos use the existing Google Drive embeds and external links.
